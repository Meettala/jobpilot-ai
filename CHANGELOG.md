# Changelog

All notable changes to this portfolio project are recorded here.

## Unreleased

### Added

- Living `AI_HANDOFF.md` for reliable continuation.
- Deterministic CI for install, TypeScript, ESLint, Vitest and production build.
- Google OSV dependency scanning.
- Strict shared JSON request validation.
- API-boundary regression tests.
- Non-root standalone Docker deployment.
- Architecture, threat model, roadmap and portfolio presentation documentation.
- Supabase constraints and indexes for the proposed persistence design.
- Social-preview artwork.
- MIT licence, security policy and contribution guidance.

### Changed

- Upgraded Next.js and `eslint-config-next` from 16.2.10 to 16.2.11.
- Reworked optional provider behaviour so it selects allow-listed evidence IDs instead of authoring unrestricted final prose.
- Added provider timeouts, HTTP checks, strict schemas, escaped delimiters and safe deterministic fallback.
- Hardened analysis and approval APIs against malformed JSON, extra fields, invalid enums and oversized strings.
- Added duplicate pending-action suppression and replayed-approval protection.
- Rewrote the README for recruiter and portfolio use.
- Clarified that Supabase and n8n files are unwired design examples, not production-connected features.

### Security

- Final cover-letter sentences remain deterministically assembled from real CV evidence.
- Missing requirements remain blocked claims.
- Tracker suggestions cannot change state before explicit approval.
- Follow-up approval remains a draft only; no send integration exists.
